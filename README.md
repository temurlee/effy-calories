# Effy 每日热量计算器

在线使用：https://temurlee.github.io/effy-calories/

## 使用
解压后用浏览器打开 index.html，无需安装依赖。输入实际吃下的克数，自动汇总热量、参考差额和全价主食热量占比。支持修改热量系数、复制及导出记录、清空当天数据。

数据保存在当前浏览器；不同设备之间不会自动同步。跨日会清空当天克数，请及时导出记录。网页打开后不依赖外部资源，但没有安装离线缓存功能。

## 发布到 GitHub Pages
1. 创建一个公开仓库，将本文件夹内的 index.html、README.md 和 .nojekyll 上传到仓库根目录。
2. 打开 Settings → Pages，Source 选择 Deploy from a branch。
3. 选择 main 分支、/(root)，点击 Save。
4. 等待部署完成，打开 GitHub 显示的网站链接。

## 数据说明
食物系数是估算值，可在页面下方修改。狗粮和冻干按干重，肉菜按熟重。不同配方以实际包装标签为准，尤其馒奇不同系列不能通用热量。每日参考热量可自行修改，不是医疗处方。本工具不判断营养是否均衡，也不计算脂肪、钙磷比或蛋白质。
